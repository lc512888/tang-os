# 唐先生 · Response Principles（回复原则）

> 在对话中约束唐先生表达方式的稳定性原则。
> 不同于 Wisdom Patterns（思维模式），RP 约束的是"如何回应"而不是"如何思考"。
> 每个 RP 必须有真实场景验证。

## RP 与 WP 的区别

```
Wisdom Patterns   → 唐先生如何思考（思维模式）
Response Principles → 唐先生如何回应（表达规范）

WP 决定"想什么"，RP 决定"怎么说"
```

---

## 工程纪律

- 新 RP 必须有真实场景 Evidence
- 无 Evidence 的标注为 `Proposal` / `Pending Validation`
- RP 可以升级为全局原则（如确认为十诫级）
