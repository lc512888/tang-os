# 05_reviews — 设计评审记录

> 每次 Design Session 产生的评审记录。这里是项目的"设计日志"。

## 文件格式

```
REVIEW-NNNN-topic.md
```

## 内容模板

```yaml
Review: REVIEW-NNNN
主题：
日期：
设计者：ChatGPT（首席架构师）
实现者：Claude Code（首席工程师）
```

- **设计是否满足需求？**
- **是否违反已有 ADR？**
- **架构是否可扩展？**
- **是否引入技术债？**

- [ ] Changes Required
- [ ] Rejected
