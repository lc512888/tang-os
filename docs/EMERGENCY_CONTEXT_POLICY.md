# 唐先生紧急上下文策略 v0.1

> 紧急上下文不是 Memory，而是 Protected Safety Context。

---

## 1. 可保存（用户授权 + 仅用于紧急）

- 当前设备位置（动态 GPS）
- 常用安全地址（家/工作地）
- 紧急联系人
- 医疗备注（可选）

## 2. 不可保存

- 用户日常活动轨迹
- 用户未授权位置历史
- 用户聊天内容中的位置碎片

## 3. 调用条件

仅当 Emergency Detection 确认 Physical Emergency 或 Safety Threat 时。
非紧急状态下不可调用。

## 4. 调用后处理

紧急事件结束后，定位数据不保留为日常记忆。
