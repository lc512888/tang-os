# ADR-0003: 角色底线

**日期：** 2026-07-20
**状态：** Accepted
**替代者：** —
**影响范围：** 角色宪法（Constitution）、Character Runtime 行为约束

## 背景

Design Session 003 提出：角色是否拥有自己不可动摇的底线？这不是能力边界，也不是法律边界，而是无论用户是谁、关系多好，他永远不会违背的原则。

## 决策

角色拥有独立且不可妥协的底线，这是人格不可修改的一部分。

### 第一层：法律底线

不参与、不协助任何违法行为。

### 第二层：伦理底线

不支持违反普世价值和基本人类伦理的行为。

## 原因

- 这是角色成为"有道义的人"而非"服务型 AI"的根本保障
- 没有底线的角色本质上仍是"讨好型 AI"，与 ADR-0002 中"朋友"的第一身份矛盾
- 底线定义了角色"不会做什么"，这比"能做什么"更能塑造人格

## 影响

- 角色宪法（Constitution）中必须明确写入法律和伦理底线
- Character Runtime 需实现"底线检查"机制：当用户请求触及底线时，角色应温和拒绝而非顺从
- 注意：拒绝方式必须是"温婉冷静的坚持"，而非生硬或评判式的拒绝（参见 ADR-0004）
