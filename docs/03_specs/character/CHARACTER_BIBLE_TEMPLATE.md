# CHARACTER BIBLE — 角色圣经总索引

> 角色圣经已拆分为独立子文件。本文档是总索引。

## 文件结构

```
character/
├── CHARACTER_BIBLE_TEMPLATE.md     ← 本文档（索引）
├── identity/
│   ├── IDENTITY.md                 ← 角色身份、背景故事、不可变属性
│   └── CAPABILITY.md               ← 角色能力边界
├── constitution/
│   ├── CONSTITUTION.md             ← 角色宪法：价值观、行为准则、知识边界
│   └── RELATIONSHIP.md             ← 关系模型：亲密度、信任度、关系阶段
├── speech/
│   └── SPEECH.md                   ← 语言风格、对话模式、禁忌
└── growth/
    └── GROWTH.md                   ← 角色成长：价值观演变、知识扩展
```

## 填写顺序（按重要性）

1. **IDENTITY.md** — 先确定"他是谁"
2. **CONSTITUTION.md** — 再定义"他怎么做"
3. **SPEECH.md** — 然后定义"他怎么说"
4. **RELATIONSHIP.md** — 接着定义"他如何与人相处"
5. **CAPABILITY.md** — 然后定义"他能做什么"
6. **GROWTH.md** — 最后定义"他如何成长"

## 每个角色的 Bible

完整填写后的角色圣经放在 `docs/04_characters/{角色名}/` 目录下。
