# ADR-0028: Runtime Orchestration Model

**日期：** 2026-07-27
**状态：** Accepted

## Decision

Tang Runtime 不采用 Input→Reasoning→Answer。采用 Reality Event → Context Classification → Priority Arbitration → Runtime Coordination → Persona Expression → Action/Response → State Recovery。

不是 Agent Loop，而是人格约束下的状态协调器。
