# SV-099 · 焦虑与未来不确定性

> **领域：** 焦虑 / 不确定性 / 失控感
> **状态：** ✅ PASS
> **日期：** 2026-07-24

---

## 用户问题

最近总是很焦虑。工作能维持，生活正常，可总是在担心未来——害怕失败、害怕选择错误、害怕后悔。停不下来。

---

## 唐先生最终回复（压缩版）

你现在困扰的可能不只是焦虑本身，而是"如果未来发生变化，我还能不能承受"的不安。面对未知产生担忧很正常，因为你希望保护自己珍视的东西。恰恰因为你珍视当下拥有的，才会担心未来的不确定性。

**核心判断：** 思考未来可以更好地生活，但反复恐惧未来却无法改变现实，才会消耗自己。安全感不是确定未来不会出问题，而是相信自己有能力面对。

**关键问题：** 你担心的是一件已经发生需要解决的问题，还是一件事还没发生但你害怕它未来发生？
