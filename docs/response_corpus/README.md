> 新场景来临时，直接参考同类回复，无需从头推理。

> **原则：** 只放 Founder 最终通过的 Version A。不放分析、不放 ADR、不放临时版本。

## 使用方式

新 Scenario 来时：
1. 确定所属领域
2. 翻阅语料库中同类场景的 Version A
3. 参考其语气、节奏、结构生成初版
4. 提交 Founder 评审
