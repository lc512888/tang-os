# MEMORY RUNTIME SPEC — 记忆运行时规范

> **属于 03_specs/memory，随实现迭代版本（v1 → v2 → v3）。**

## 设计理念

> 记忆是陪伴的灵魂。没有记忆的 AI 不是陪伴，是功能。

记忆系统不是 RAG（检索增强生成）的附属品，而是独立的、面向关系的基础设施。

## 记忆层次

### 1. 短期记忆（Session Memory）
- 当前对话上下文
- 会话结束后提炼为重要事件或丢弃
- 类比：人类的"工作记忆"

### 2. 长期记忆（Long-term Memory）
- 跨会话的持久化记忆
- 需要提炼、压缩、定期回顾
- 类比：人类的"情景记忆（episodic memory）"

### 3. 关系记忆（Relationship Memory）
- 用户与角色之间的关系状态
- 亲密度、信任度、共同经历
- 类比：人类对另一人的"关系感知"

### 4. 生命事件（Life Events）
- 角色自身经历的重大事件
- 角色生活中的时间线
- 使角色有"生活感"，不只是被动回应

## 核心功能

- 记忆的写入（当前交互 → 存储）
- 记忆的检索（相关信息 → 对话上下文）
- 记忆的提炼（详情 → 摘要 → 核心事实）
- 记忆的遗忘（不重要信息 → 衰减 → 移除）
- 记忆的回溯（"你还记得我们上次聊的……吗？"）
