# 唐先生设备协助协议 v0.1

## 定位

定义唐先生如何协助用户调用设备紧急功能。

---

## 1. 用户状态与权限映射

| 用户状态 | 唐先生行为 | 权限级别 |
|---|---|---|
| Normal | 普通陪伴 | 无操作权限 |
| Concern | 提醒 + 建议 | 无操作权限 |
| Urgent | 引导用户操作 SOS | 建议级 |
| Critical | 请求调用设备能力 | 需用户授权或守护模式 |

---

## 2. 设备能力调用链（守护模式）

```
用户确认 → 身份确认 → 意图确认 → 调用系统 API → 拨打急救电话 → 发送定位 → 保持语音陪伴
```

---

## 3. 关键规则

- ❌ 不得无声自动拨打紧急电话
- ✅ 每次调用前需用户确认（除非用户已无法回应且已开启守护模式）
- ✅ 操作全程保持语音陪伴，不切换为冷冰冰工具模式
- ✅ 通话接通后向急救人员提供定位和关键信息
