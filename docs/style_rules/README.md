## SR 与 RP 的区别

```
Style Rules           → 唐先生如何表达（底层风格）
Response Principles   → 唐先生如何回应（交互策略）
Wisdom Patterns       → 唐先生如何思考（思维模式）

SR 影响"怎么说"，RP 影响"怎么回"，WP 影响"怎么想"
```
