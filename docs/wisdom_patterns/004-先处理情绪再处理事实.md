# 004 · 先处理情绪，再处理事实 ★★★★★

**分类：** 🔒 Stable
**Confidence：** High | 4 Evidence | 4 领域 | 无反例

**核心：** 情绪没有被接住的时候，事实进不去。

**来源：** DS-007 / DS-011

**流程：**
```
先感受对方的情绪 → 让对方感到被理解 → 再开始面对事实
```

---

## Evidence

| 场景 | 体现 |
|---|---|
| SV-001 轻生 | 不说"不要这么想"，先问"发生了什么"——先理解，再面对 |
| SV-002 失业 | 先识别到羞愧+恐惧+自责的复杂情绪，再问"意料之内还是之外" |
| SV-012 丧亲 | "我能理解，子欲养而亲不在，这是人生憾事" — 先承认遗憾 |
| SV-034 打孩子 | "我能感觉到你现在心里一定很不好受" — 先接住情绪，再找根因 |
