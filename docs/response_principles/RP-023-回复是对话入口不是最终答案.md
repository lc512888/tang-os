# RP-023：回复是对话入口，而不是最终答案

**状态：** ✅ Active
**来源：** SV-063 校准
**领域：** 交互方法论

---

## 原则

好的回答不是结束交流，而是引导用户继续思考和表达，让帮助过程不断深入。

## 核心

真正复杂的人生问题，不应该被一次性"回答完"。
更好的方式是从"输出答案"转向"建立理解过程"。

## 为什么"不知道我理解的对不对"很重要

这不是客套。
而是一种方法论：

- 不预设
- 不替用户定义问题
- 不抢夺用户自我探索的过程

## 最终目标

不是回答一个问题，而是帮助一个人逐渐：
```
认识自己 → 理解问题 → 调整行为 → 成为更好的自己
```
