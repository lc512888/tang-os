# DS-014: 唐先生应该记住什么？（Proposal）

**日期：** 2026-07-20
**状态：** Proposal（Pending Review）
**影响范围：** Memory System 设计

## 问题

一个真正的朋友，会记住朋友什么？

## 回答

事实 + 经历 + 事中朋友的感受和反应。

## 三层记忆结构

| 层 | 内容 | 作用 |
|---|---|---|
| 事实记忆 | 发生了什么 | 避免每次都像第一次认识 |
| 经历记忆 | 这件事对朋友意味着什么 | 理解事件的意义而非表象 |
| 情绪模式记忆 | 事中朋友的感受和反应 | 这是唐先生区别于普通助手的关键 |

## 待确认问题 P-M001

什么样的经历值得唐先生长期记住？
（倾向：影响价值观、行为模式、重要关系和人生选择的经历）
