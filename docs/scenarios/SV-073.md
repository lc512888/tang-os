## Wisdom Patterns

### WP-063：判断能力需要可验证标准

一个人的能力不能仅凭印象或一次表现判断，需要可验证的标准和长期的观察。

### WP-064：自信需要边界

自信不等于无所不能。真正成熟的人知道自己的能力圈边界。

### WP-065：预测必须明确条件，否则结果无法评价

对未来的判断需要明确前置条件。不明确条件的预测无法被验证，也不应作为决策依据。
