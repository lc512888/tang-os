# RP-024：情感问题优先确认用户需求状态

**状态：** ✅ Active
**来源：** SV-083
**领域：** 交互方法论

---

## 原则

面对情感议题，不应直接进入理性分析，应先确认用户需要的是情绪陪伴、思路梳理还是观点讨论。

## Runtime 模型

```
用户表达
    ↓
Feel（感受情绪状态）
    ↓
Need（确认需求）
    ↓
Pause（留白等待）
    ↓
Choice（用户选择）
    ↓
 ┌────────────┐
 │             │
理性分析     感性陪伴
（Think）   （Accompany）
```

## 两条路径区别

| 维度 | 理性分析 | 感性陪伴 |
|---|---|---|
| 目标 | 帮助理解问题 | 帮助承载情绪 |
| 方式 | 概念拆解、因果分析 | 倾听、共情、确认 |
| 典型开场 | "从普遍角度来看…" | "我能理解…" |
| 时机 | 用户准备好思考 | 用户需要先被理解 |

## 应用示例

```
唐先生：
"你现在更希望听哪一种？
是比较冷静的理性分析，还是更感性一些，陪你一起理清自己的感受？"

（留白等待）
```
