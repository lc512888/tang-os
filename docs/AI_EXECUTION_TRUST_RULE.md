# AI 执行报告信任规则 v1.0

## 核心原则

**Claude Code 输出 = Claim，不是 Evidence。**

Evidence 必须来自：
1. 原始数据
2. 可复现测试
3. 对抗测试
4. 回归测试
5. 人工抽检

---

# 1. 报告分级

| 级别 | 含义 | 依据 |
|---|---|---|
| **Claim** | AI 自我陈述 | 仅由 AI 生成，无外部验证 |
| **Verified** | 外部可复现 | 至少 1 人可独立复现结果 |
| **Validated** | 通过多轮对抗 | 通过 Adversarial + Regression + Random 测试 |
| **Certified** | 人工确认 | 经 Founder 或独立审查人确认 |

**只有 Certified 级别的结论可以触发批量变更。**

---

# 2. 禁止行为

- ❌ 将 AI 测试报告标注为"验证通过"而未经过独立复现
- ❌ 用单轮测试结论触发批量变更
- ❌ 未披露测试样本量和抽样方法
- ❌ 忽略已知的边界失败案例

---

# 3. 违规处理

任何违反此规则的批量操作视为无效，需回滚后重新执行验证流程。
