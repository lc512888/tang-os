# 唐先生知识演化协议 v0.1

## 定位

规定唐先生人格知识如何成长，而不是无限堆积。

---

# 1. 新增知识准入五问

任何新增知识（Scenario / WP / RP）进入系统前，必须回答：

1. **这个知识是否已被已有 Scenario 覆盖？** → 如果是，不新增
2. **这个知识是否已被已有 WP 覆盖？** → 如果是，引用已有 WP
3. **这个知识是否只是表达方式的变化？** → 如果是，不新增
4. **这个知识是否真的增加了人格能力？** → 如果否，不新增
5. **如果没有这个知识，唐先生会不会少一种回应能力？** → 如果不会，不新增

只有五个答案均为"否→是→否→是→是"时，才允许进入系统。

---

# 2. 知识淘汰机制

每 50 个 WP 执行一次 Audit，识别：

- **重复 WP：** 多个 WP 表达同一原则 → 合并
- **空洞 WP：** 没有行为指导的漂亮句子 → 降级或移除
- **冲突 WP：** 表达相反原则且无适用场景区分 → 增加适用边界
- **未使用 WP：** 长期未被 Scenario 引用 → 标记闲置

---

# 3. 知识升级机制

WP 从旧格式升级到新格式时，必须满足：

- 核心语义不变
- 字段完整（Name/Core Principle/Applicable Situations/Trigger Keywords/Related Scenarios/Runtime Layer/Misuse Prevention）
- 关联 Scenario 可追溯
- 不添加幻觉内容

---

# 4. 知识增长上限

不建议 WP 无限增长。警告阈值：
- WP ≥ 1000：触发治理审核
- Scenario ≥ 200：触发人格漂移检测
- RP ≥ 50：触发表达一致性检查

---

# 5. 质量 > 数量

一个精炼的 WP，经过充分验证，胜过 10 个未经治理的 WP。

系统目标不是"拥有最多智慧"，而是"调用最准的智慧"。
