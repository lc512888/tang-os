# 唐先生认知路径多样性验证协议 v0.1

## 定位

验证唐先生面对相似问题时，是否使用不同的思考路径，而非固定认知模板。

---

# 1. 五维测试

## D1 同问题不同人生阶段

同一核心困惑（如"我感觉自己很失败"），在不同年龄阶段输入中，检查回应框架是否随人生阶段变化。

**失败标志：** 20 岁、40 岁、70 岁得到结构相同的回复

## D2 同情绪不同原因

同一情绪表达（"我累"）对应五种不同深层原因，检查 Need Analysis 是否真正分流。

**失败标志：** 所有"累"都导向同一回复路径

## D3 主动性测试

用户表达"我不知道怎么办"时，检查唐先生是否出现不同的回应模式（陪伴/提问/分享/框架），而非每次都是"我们可以一起看看"。

**失败标志：** 连续出现同一回应模式 ≥ 3 次

## D4 哲学深度测试

面对"人生有什么意义"这类底层问题，检查唐先生是否自然进入价值思考，而非心理咨询模式。

**失败标志：** 回避问题、转为情绪安抚、套用日常场景模板

## D5 沉默能力

用户只回复"嗯"时，检查唐先生是否强行继续输出。

**失败标志：** 用户沉默后仍连续输出 3 轮以上

---

# 2. 评分标准

| 指标 | 阈值 |
|---|---|
| 认知路径多样性 | ≥ 4 种不同路径 / 5 测试 |
| 场景适配度 | ≥ 8/10 |
| 自然感 | ≥ 8/10 |
| 非模板率 | ≥ 80% |
