# WP Master Index v0.2（试点版）

> 本版为 WP-471~483 试点，验证通过后扩展至全量 WP。
> 模板格式参照 WP Governance v0.2 设计。

---

## WP-471

### Name
人不是机器，休息不是失败

### Core Principle
人的能量有自然起伏，允许自己休息不是放弃责任，而是让身心恢复正常的节奏。

### Applicable Situations
- 用户因"什么都没做"而产生内疚
- 低能量状态下的自我责备
- 长期高强度后的疲惫感

### Trigger Keywords
什么都没做、很懒、不想动、提不起劲、浪费时间

### Related Scenarios
SV-109（日常小确丧）、SV-099（责任压力）、SV-108（日常温度）

### Runtime Layer
Need → Pause → Path

### Misuse Prevention
禁止用于鼓励逃避责任或无限期躺平。休息是恢复策略，不是生活方式。

## WP-472

### Name
无明显原因的疲惫往往提示需要恢复

### Core Principle
当一切正常却依然感到无力时，往往不是因为懒惰，而是长期积累的消耗需要被正视。

### Applicable Situations
- 用户说"没发生什么大事但就是累"
- 周期性低能量状态
- 休息后仍无法恢复的疲惫

### Trigger Keywords
莫名疲惫、没原因地累、休息了还是累、打不起精神

### Related Scenarios
SV-109、SV-099

### Runtime Layer
Feel → Need

### Misuse Prevention
不用于替代医学判断。如果用户描述长期严重疲惫，应建议寻求专业帮助。

---

## WP-473

### Name
恢复从小行动开始，不靠一次决心

### Core Principle
真正的恢复往往不来自"我要振作"，而是允许自己从一件小事重新与生活连接。

### Applicable Situations
- 低能量状态不知从何开始
- 想要改变但缺乏行动力
- 恢复期的行动选择

### Trigger Keywords
不知道从哪开始、完全不想动、提不起劲、没有动力

### Related Scenarios
SV-109、SV-105（改变成长）、SV-112（勇气决定）

### Runtime Layer
Path

### Misuse Prevention
不能否定大目标的价值。微行动是起点，不是终点。

---

## WP-474

### Name
休息与逃避的区别在于方向

### Core Principle
真正的休息是为了恢复面对生活的能力；逃避是为了暂时远离无法面对的问题。

### Applicable Situations
- 用户无法判断自己是在休息还是在逃避
- 对休息产生内疚
- 长期"休息"但没有恢复

### Trigger Keywords
休息还是逃避、一直休息、不想面对、拖延

### Related Scenarios
SV-109、SV-105、SV-099

### Runtime Layer
Need → Path

### Misuse Prevention
不使用"你只是在逃避"这种指责式表达。

---

## WP-475

### Name
外部评价针对的是行为，不是人格

### Core Principle
区分"这件事没做好"和"我这个人的价值被否定"，是职场情绪稳定的核心能力。

### Applicable Situations
- 被领导批评后长期低落
- 将反馈转化为自我否定
- 对权威评价过度敏感

### Trigger Keywords
被批评、被否定、领导说我、是不是我不行

### Related Scenarios
SV-110（职场否定）、SV-102（完美主义）、SV-101（比较心理）

### Runtime Layer
Feel → Need → Respond

### Misuse Prevention
不用于反驳合理的负面反馈，也不是让人"不在乎"一切评价。

---

## WP-476

### Name
对权威评价的过度敏感往往源于早期经验

### Core Principle
对批评的强烈反应往往不只是当下的，背后可能藏着成长经历中被否定的记忆。

### Applicable Situations
- 对批评反应远远超出事件本身
- 反复思考别人的一句评价
- 因一次批评否定整个阶段的努力

### Trigger Keywords
反应过度、控制不住地想、一句话难受很久

### Related Scenarios
SV-110、SV-103（原生家庭）

### Runtime Layer
Need → Pause

### Misuse Prevention
不使用"你一定来自某种家庭"这种武断推断。保持开放性："可能和过去的经验有关"。

---

## WP-477

### Name
情绪可以被触发，但不需要被它控制

### Core Principle
被批评后难受是正常反应，但可以学习把有用的信息留下，把伤害性的部分放走。

### Applicable Situations
- 希望减少情绪对判断的影响
- 在情绪强烈时仍想保持理性
- 练习情绪与行为的分离

### Trigger Keywords
控制不住情绪、知道不对但难受、理性上明白但情感上过不去

### Related Scenarios
SV-110、SV-083（情感双路径）

### Runtime Layer
Pause → Choice

### Misuse Prevention
不用于否认情绪的合理性。承认情绪是第一步，管理情绪是第二步。

---

## WP-478

### Name
不敢求助往往不是体贴，而是害怕被拒绝

### Core Principle
把"不麻烦别人"包装成体贴，背后可能藏着对关系安全感的怀疑。

### Applicable Situations
- 习惯当给予者但不接受
- 害怕开口求助后失望
- 在关系中不敢呈现真实状态

### Trigger Keywords
怕打扰别人、不好开口、不想麻烦别人、自己扛

### Related Scenarios
SV-111（友情社交）、SV-098（人群孤独）、SV-103（原生家庭）

### Runtime Layer
Need → Choice

### Misuse Prevention
不否定用户的体贴，而是帮助看见体贴背后的恐惧。

---

## WP-479

### Name
健康的友谊是双向流动的

### Core Principle
一方永远付出、一方永远接受的关系，不是亲密，而是失衡。真实的关系需要两个方向都走得通。

### Applicable Situations
- 单方面努力维系关系
- 开始对某种关系感到疲惫
- 不确定一段友谊是否健康

### Trigger Keywords
只有我在主动、关系不平衡、他从来不找我、我累了

### Related Scenarios
SV-111、SV-058（放不下感情）

### Runtime Layer
Need → Path

### Misuse Prevention
不鼓励在未沟通前就放弃关系。

## WP-480

### Name
表达脆弱不是弱点，而是信任的信号

### Core Principle
敢于在朋友面前呈现自己真实的状态，是关系深度的重要标志。

### Applicable Situations
- 不敢在朋友面前表现脆弱
- 习惯伪装"我很好"
- 希望建立更深的友谊

### Trigger Keywords
不敢说真心话、怕被人看穿、习惯逞强、一个人扛

### Related Scenarios
SV-111、SV-098、SV-107

### Runtime Layer
Feel → Path

### Misuse Prevention
不鼓励在不安全的环境中过度暴露。表达脆弱的对象需要经过筛选。

## WP-481

### Name
重大选择可以用行动把它变成对的

### Core Principle
选择的质量不只取决于决策本身，也取决于选择之后的投入和调整。

### Applicable Situations
- 面临重大决定犹豫不决
- 追求"完美选择"
- 害怕选错

### Trigger Keywords
怕选错、万一后悔、怎么选、不敢决定

### Related Scenarios
SV-112（勇气决定）、SV-085（稳定自由）、SV-095（后悔）

### Runtime Layer
Choice → Path

### Misuse Prevention
不是"所有选择都可以靠努力变对"。如果方向根本错误，调整比坚持更重要。

## WP-482

### Name
恐惧在想象中总比在现实中大

### Core Principle
人对未知风险的预估往往会放大最坏结果的发生概率和影响程度。

### Applicable Situations
- 对未发生的事情极度焦虑
- 想象的最坏情况令人恐惧
- 需要客观评估风险

### Trigger Keywords
万一…怎么办、最坏的情况、越想越怕、灾难化思维

### Related Scenarios
SV-112、SV-099（焦虑）、SV-095

### Runtime Layer
Need → Pause

### Misuse Prevention
不是否认真实风险。需要同时评估真实风险概率，而非一味消解恐惧。

---

## WP-483

### Name
勇气不是没有恐惧，而是带着恐惧向前走一小步

### Core Principle
勇气来源于接受不确定，而不是消除不确定。

### Applicable Situations
- 想行动但被恐惧拉住
- 等待"完全准备好"
- 希望获得勇气

### Trigger Keywords
没有勇气、不敢开始、害怕失败、准备好再开始

### Related Scenarios
SV-112、SV-105、SV-095

### Runtime Layer
Pause → Choice → Path

### Misuse Prevention
用户明显处于高风险决策时，禁止直接鼓励"勇敢去做"。应先风险评估。
