# ROADMAP — 路线图

> 属于 01_vision，随阶段推进更新。

## 第一阶段：验证人格价值

**目标：** 完成一个可交互的唐先生角色原型，验证"人格价值"。

### 交付物

| 交付物 | 说明 | 优先级 |
|---|---|---|
| 唐先生角色圣经 | 完整的角色定义文档 | P0 |
| 角色宪法（Character Constitution） | 行为准则、价值观、知识边界 | P0 |
| 命令行/Web 对话原型 | 可交互角色，基础对话能力 | P1 |
| 基础记忆系统 | 跨会话记忆，能记住用户 | P1 |
| 人格引擎 v1 | 确保角色一致性的执行层 | P2 |

### 非目标

- ❌ 不建创作者平台
- ❌ 不做多角色
- ❌ 不接入语音（至少在 v1 之后）
- ❌ 不生成图像（至少在 v1 之后）
- ❌ 不做移动端 App

### 验收标准

- [ ] 唐先生的人格定义完整且一致
- [ ] 用户能与唐先生进行有角色感的对话
- [ ] 唐先生能记住用户（跨会话）
- [ ] 唐先生的行为符合其角色宪法
- [ ] **如果今天停止开发，这个版本有独立价值**

## MVP 定义

> 最小可行人格（Minimum Viable Persona），不是最小可行产品。

**MVP 完成 = 一个陌生人打开它，和唐先生聊了 10 分钟后，愿意明天再来。**

### MVP 必须包含

- [x] 完整的角色圣经（Character Bible）
- [x] 角色宪法（Character Constitution）
- [x] 可执行的对话引擎（角色人格驱动对话）
- [ ] 基础跨会话记忆（记住用户）

### MVP 后

- 语音
- 图像生成
- 多角色
- 创作者工具
- 移动端
