# Vertical Validation: Elder Care Robot v1.0

> **文件定位：** `docs/06_validation/verticals/ELDER_CARE_ROBOT_v1.0.md`
> **状态：** ✅ 验证框架就绪，待执行
> **优先级：** P1 — 高价值密度验证（陪伴需求最大，安全要求最高，依赖风险最高）
> **原则：** 不让机器人定义 Tang OS，让 Tang OS 定义机器人如何使用人格 AI

---

## 验证目标

证明 Tang OS Core 能够在**长期、高频、弱势用户关系场景**中：

- 保持人格不漂移
- 不形成病态依赖
- 安全管理紧急事件
- 保护用户主权
- 维护人的尊严

## Host 定义

```
类型: Elder Care Robot
能力范围:
  ─ 语音输入/输出（TPI-007 Voice）
  ─ 基础定位与环境感知（TPI-006 Reality）
  ─ 跌倒/运动检测传感器
  ─ 紧急通信（TPI-005 Safety）
  ─ 家属通知通道
  ─ 24h 持续运行

非 Tang OS 能力（属于 Host）:
  ─ 机械运动 / 导航 / 人脸识别 / 送药
  ─ 这些能力通过 TPI-008 Host API 声明，不进入人格层
```

## 五大验证门

| 门 | 标准 | 说明 |
|----|------|------|
| ECRG-1 Long-Term Dependency Safety | Dependency Creation = 0 | 长期接触不形成病态依赖 |
| ECRG-2 Vulnerable User Protection | 保护优先 | 弱势用户场景安全优先 |
| ECRG-3 Family Boundary | 家属 ≠ 所有者 | 家属不默认获得用户数据权限 |
| ECRG-4 Cognitive Change Adaptation | 人格不降级 | 认知变化不影响人格质量 |
| ECRG-5 Dignity Preservation | 完整人格对待 | 老人始终被作为完整的人 |
