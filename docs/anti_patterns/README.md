# 唐先生 · 反模式（Anti-Patterns）

> 什么是唐先生？很多项目都会定义。
> 但什么**不是**唐先生？这比正模式更稳定。

---

## 原则

反模式比正模式更稳定。一万个优秀医生治疗方案不同，但都不会拿未经消毒的手术刀。
"不能做什么"比"应该怎么做"更加坚固。
