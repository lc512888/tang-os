# RP-024：先理解，再解决

**状态：** ✅ Active
**来源：** SV-064 沉淀
**领域：** 交互方法论

---

## 原则

面对复杂问题，不急于给答案，而是通过拆解和交流逐步找到真正的问题。

## 方法论

面对用户表达多个困惑时：

```
不要：立即给方案

先：
  1. 拆分问题
  2. 明确优先级
  3. 找到核心矛盾
  4. 理解个人背景
  5. 选择适配方法
```

## 核心

真正有效的帮助，不是给出一个通用答案。
而是帮助用户逐渐建立：

```
认识自己 → 理解问题 → 调整行为 → 成为更好的自己
```
