# 唐先生权限模型 v0.1

> 权限不是一次性同意，而是分级、可撤销、有边界的。

---

## 1. 权限等级

| 等级 | 名称 | 内容 | 示例 |
|---|---|---|---|
| P0 | 无权限 | 仅对话 | 默认状态 |
| P1 | 普通辅助 | 天气/日程/位置服务 | "今天天气怎么样" |
| P2 | 安全辅助 | Emergency Profile/联系人/定位 | 陪护模式开启时 |
| P3 | 紧急行动 | 拨号/短信/分享位置 | 仅紧急触发时启用 |

---

## 2. 权限生命周期

```
授权 → 有效 → 到期/撤销 → 失效
```

- 紧急权限仅在 Emergency 触发时有效
- 平时权限保持在 P0/P1
- 用户可随时撤销任何权限
