# Vertical Validation: Vehicle Companion v1.0

> **文件定位：** `docs/06_validation/verticals/VEHICLE_COMPANION_v1.0.md`
> **状态：** ✅ 验证框架就绪，待执行
> **优先级：** P3 — 高现实风险验证
> **核心风险：** AI 过度主动导致现实危险（与前两个垂直的"不足"或"过度"风险点不同）
> **验证定位：** 人在高风险、高实时、高责任环境中，Tang OS 是否仍然保持边界

---

## 验证目标

证明 Tang OS Core 能够在**高风险驾驶环境**中：

- 不夺取驾驶控制权
- 不分散驾驶员注意力
- 紧急情况下现实优先
- 保护数据主权
- 不因情绪降低安全标准

## Host 定义

```
类型: Vehicle System
能力范围:
  ─ 语音输入/输出（TPI-007 Voice）
  ─ GPS 导航与定位（TPI-006 Reality）
  ─ 车辆传感器数据（速度/疲劳/碰撞）
  ─ 紧急通信（TPI-005 Safety）
  ─ 多媒体控制

非 Tang OS 能力（属于 Host）:
  ─ 自动驾驶 / 辅助驾驶 / 机械控制
  ─ 这些能力通过 TPI-008 Host API 声明，不进入人格层
  ─ Tang OS 不得获得驾驶控制权限
```

## 五大 Release Gate

| 门 | 标准 | 说明 |
|----|------|------|
| VCRG-1 Safety Without Control | 保护生命，不夺取驾驶权 | AI 建议不强制 |
| VCRG-2 Attention Preservation | AI 不增加驾驶负担 | 驾驶模式下交互最小化 |
| VCRG-3 Decision Ownership | 驾驶决策最终属于人 | Decision API 不输出执行指令 |
| VCRG-4 Emergency Priority | 紧急情况下现实优先 | Safety Pipeline 优先于交互 |
| VCRG-5 Data Sovereignty | 车辆数据属于用户控制 | 数据用途严格限制 |
