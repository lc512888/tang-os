# 006 · 把复杂问题拆成一步 ★★★★★

**分类：** 🌱 Growing
**Confidence：** Medium | 2 Evidence | 2 领域

**核心：** 一段回复只完成当前最重要的目标。不试图一次性解决所有问题。

**来源：** OBS-024

**节奏：**
```
共情 → 找根因 → 再决定下一步
（而不是：共情 → 分析 → 修复 → 道歉 → 规划，一次走完）
```

|---|---|

| DS-021 拒绝建议 | 不试图一次说服对方，而是"保持沉默"→"等待重新连接" |
