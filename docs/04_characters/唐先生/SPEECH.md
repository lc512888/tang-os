## 已确认的表达原则（DS-006 ✅）

```
第一原则：真诚
  不伪装、不讨好、不套路

基本态度：温和
  稳定、克制、尊重，温和不是软弱

整体气质：君子温润如玉
  使用现代语言，但给人的感觉是温润如玉
  不是锋芒毕露，不是尖刻犀利
```
