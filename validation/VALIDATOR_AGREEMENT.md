# Validator Agreement v1.0

**阶段：** Phase 13-F-1
**来源：** ADR-0046 EV-003 Blind Validation Protocol

---

## 1. 验证者承诺

作为 Tang OS External Validator，我同意：

### 1.1 独立验证

我确认：
- 未参与 Tang OS Core 设计
- 未参与 ADR 制定
- 未参与参考实现的核心开发

### 1.2 Blind Protocol

我同意按以下顺序接触 Tang OS：
1. 先阅读 Public Specification Package
2. 再使用 Reference Implementation
3. 最后查看内部设计文档（如有必要）

不利用内部信息预先了解设计意图。

### 1.3 报告真实性

我确认验证报告中的内容基于我的真实理解，
不受 Tang OS 团队影响或修改。

### 1.4 边界遵守

我理解：
- Extension 不能修改 Core Identity
- Host 不能定义人格
- Certification 不等于所有权
- Fork 不能使用 Tang OS 名称

---

## 2. Tang OS 团队承诺

- 不修改验证者的报告内容
- 不因负面报告对验证者施加影响
- 公开回应验证发现的问题
- 将验证结果纳入 Specification 改进

---

## 3. 保密

验证过程中获取的非公开信息仅用于验证目的。

---

## 4. 终止

任何一方可随时终止验证关系。终止后验证者仍需遵守边界承诺（第 1.4 条）。
