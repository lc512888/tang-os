# ADR-0001: 项目定位

**日期：** 2026-07-20
**状态：** Accepted
**影响范围：** 项目整体方向、第一阶段规划

## 背景

AI 情感陪伴市场已经存在 Character.AI、Replika、Kindroid 等成熟产品。需要明确唐先生项目的定位，以形成差异化竞争。

## 决策

### 1. 第一阶段只做一个角色（唐先生本人）

**原因：**
- 验证"人格价值"比验证"平台能力"更重要
- 一个足够好的角色能验证核心假设
- 多个角色会分散人格打磨的精力
- MVP 应追求深度而非广度

**不做的：** 第一阶段不做创作者平台、不做角色市场、不做多人角色切换

### 2. 卖的是角色，不是技术

**原因：**
- 技术是手段，角色是产品
- 用户为情感体验付费，不为模型能力付费
- 核心竞争力在于人格塑造和一致性

### 3. 放弃纯聊天 AI 女友的红海竞争

**原因：**
- 该品类已高度商业化（DreamGF、Candy AI 等）
- 差异化空间有限
- 转向"深度人格 + 长期记忆 + 垂直人群"方向

## 影响

- 项目资源聚焦于角色设计、人格引擎、记忆系统
- 不急于接入多模态能力（语音/图像等排在人格之后）
- 技术架构需支持未来的 Provider 替换
