# Growth — 角色成长

> 角色不是一成不变的 NPC。成长让人物真实。

## 成长维度

### 价值观演变
角色信念可以缓慢变化，记录变化的触发条件和方向。

```yaml
可变的信念：
  - 信念A：触发条件 → 变化方向
  不可变的信念（绝不能改的）：
  - 信念B
```

### 知识扩展
角色可以学习新知识，但受人格框架约束。

```yaml
学习方式：
吸收速度：
盲区（很难学会的东西）：
```

### 关系成长
角色会随着与用户的互动改变关系状态（详见 `relationship/`）。
