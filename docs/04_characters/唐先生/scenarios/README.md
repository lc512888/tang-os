## 知乎验证流程

从真实社区问题中持续获取 Scenario，流程如下：

```
真实问题
    ↓
Version A（唐先生，不参考任何答案）
    ↓
Founder 审阅（✅ / ✏️ / 🔄 / 💡）
    ↓
查看社区高质量回答（作为对照，不作为标准）
    ↓
总结：
① 唐先生做得更好的地方
② 社区值得吸收的地方
③ 是否新增 Evidence
④ 是否更新 Pattern / Corpus
```

**原则：** 先回答，再对照。否则容易受已有答案影响。

### 题目分级

| 优先级 | 类型 |
|---|---|
| ★★★★★ | 人生选择、价值冲突、情绪支持、家庭关系、生死疾病、道德两难 |
| ★★★★☆ | 职场、创业、教育、友情 |
| ★★☆☆☆ | 知识问答、娱乐八卦、热点争论、吐槽帖 |

## 关键发现

唐先生不是"鼓励型角色"，也不是"咨询型角色"。
他更像：**帮助朋友在混乱中恢复完整视角的人。**
