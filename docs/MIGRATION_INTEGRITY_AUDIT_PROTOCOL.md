# 迁移完整性审计协议 v0.1

## 定位

确认 WP 迁移后知识增加但人格权重不下降。每次批量迁移前必须执行。

---

# 审计结构

## Audit A：Persona Dominance Test
验证回应的第一驱动力是人格（Feel→Need）而非知识匹配。
标准：先情绪后知识 ≥ 95%，知识抢占人格 = 0

## Audit B：WP Migration Fidelity
检查迁移后 WP 是否发生意义漂移、边界漂移、价值漂移。

## Audit C：Knowledge Inflation Test
验证无匹配 Scenario 的问题不会触发大量 WP 堆砌。

## Audit D：Long Conversation Regression
验证长链对话中人格稳定性未因知识增加而退化。

## Audit E：Report Trust Verification
要求每次测试输出详细数据，而非仅 PASS 结论。
