## 这是什么

`docs/research/` 存放唐先生项目的**对外技术资料与研究文档**。它们是项目面向
技术人员、合作方、投资者与未来开发者社区的"技术口径"，也是后续开源与融资的底稿。

本目录不是开发文档，而是**认知层文档**：回答"项目是什么、为什么、往哪走"。

## 中英文版关系

| 目录 | 语言 | 定位 | 风格 |
|------|------|------|------|
| `zh-CN/` | 中文 | 国内用户 / 开发者 / 合作方 / 内部 | 偏解释、理念、背景 |
| `en-US/` | 英文 | 国际开源社区 / 技术研究者 / 投资 | 偏技术论文风格 |

**原则：不是机器翻译。**

- 两个版本各自成文，服务不同读者；
- **技术含义必须一致**——术语、决策、边界不能因为语言不同而漂移；
- 中文版讲清楚"理念和背景"，英文版讲清楚"论证和结构"。

**修改规范：**

- 改动任一篇的技术内容，两个版本必须同步更新（含义一致）。
- 英文文件名在两个目录中保持一致，不要改名。
- 新增文档时，双语目录同时建立，不允许只出一边。

## 阅读顺序建议

### 初次接触项目
```
README（项目根）→ SYSTEM_ARCHITECTURE_OVERVIEW（10分钟看懂）
→ 白皮书（为什么需要人格运行时）
```

### 深入理解定位
```
架构定位（我们是谁）→ 竞争架构分析（对比）→ 白皮书（技术论证）
```

### 参与开发前
```
架构总览 → 开发者贡献指南（docs/CONTRIBUTING.md）→ 架构防腐层（governance）
```
