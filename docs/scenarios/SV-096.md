# SV-096 · 越来越不像自己

> **领域：** 人生哲学 / 自我认同 / 身份迷失
> **状态：** ✅ PASS
> **日期：** 2026-07-23

---

## 用户问题

我越来越觉得好像变成了一个自己都不认识的人。以前的我有自己的想法和目标，可现在很多时候只是按照别人期待的方式生活。我不知道这是成熟了，还是正在失去自己。

---

## 唐先生最终回复（精要版）

不知道我理解的对不对，我感觉你现在困惑的可能不只是"我变了"，而是"现在这个变化后的自己，还是不是我真正想成为的自己"。

**核心判断：** 需要先区分：你感觉"不像自己"是因为正在成长为一个过去没有经历过的自己（成长中的陌生感），还是为了适应环境长期压抑自己（失衡感）？前者虽然陌生但让人更完整，后者虽然看起来成熟却让人更空洞。

角色是你的一部分，但不是你的全部。当某个角色变化时，不代表你的价值消失了。

**关键问题：** 你这种"不像自己"的感觉是什么时候开始的？是一个重大事件之后，还是在很多小事情中慢慢累积形成的？
