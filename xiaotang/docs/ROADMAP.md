# xiaotang 路线图

---

## v0.1 MVP（当前）

**目标：验证人格体验闭环**

### 范围

| 功能 | 状态 |
|------|------|
| CLI 交互模式 | ⬜ |
| Tang OS 集成 | ⬜ |
| DeepSeek LLM 接入 | ⬜ |
| 多轮对话上下文 | ⬜ |
| 无 API Key 降级模式 | ⬜ |

### 暂不实现

- 用户账号
- 社交功能
- 记忆持久化
- 商用系统
- 多角色

### 验收标准

> 用户打开 xiaotang，第一次聊天时，能明显感受到这是唐先生，而不是普通 LLM。
