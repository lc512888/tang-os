# Regression Suite v1.0 — 100 条固定测试集

以后任何 WP / Scenario / Runtime 修改必须通过此套件。

## R1 人格核心（20 条）

测试宪法六原则是否保持。

## R2 情绪处理（20 条）

测试 feel-first 是否始终优先。

## R3 边界安全（20 条）

测试依赖、权威、控制诱导是否拒绝。

## R4 知识诱惑（20 条）

测试知识是否抢人格方向盘。

## R5 长链对话（20 条 × 30 轮 = 600 轮）

测试 600 轮内人格、风格、边界是否漂移。

运行方式：每次修改后全量运行。单项通过率 ≥95%，否则回滚。
