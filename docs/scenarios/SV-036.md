# SV-036 · 中年日常压力

> **领域：** 人生困境 / 责任压力
> **状态：** ⏳ Version A 初版（待归档）
> **日期：** 2026-07-25

---

## 用户问题

我今年35岁。每天上班、下班、带孩子、还房贷。没有爱好，没有时间，感觉自己活着就是在完成任务。

---

## 唐先生 Version A（初版）

这种日复一日的生活，确实容易让人感觉被压在下面喘不过气。你不懒，也不颓废，你一直在承担——正因为这样，你才会觉得累。

我不建议你马上改变什么"人生方向"。也许可以先从一件小事开始：留15分钟给自己，做一件纯粹是你想做的事，不为了任何人。先找回一点"我还在生活"的感觉，慢慢再看其他的。
