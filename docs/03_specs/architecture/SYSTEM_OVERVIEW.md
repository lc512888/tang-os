# SYSTEM OVERVIEW — 系统架构概览

> **属于 03_specs/architecture，随架构演进更新。**

## 架构原则

1. **人格逻辑与模型调用分离** — 角色行为由人格引擎控制，LLM 只是实现手段
2. **Provider 可替换** — LLM、TTS、图像生成等外部服务通过适配器模式接入
3. **记忆独立于对话** — 记忆系统是独立基础设施，不嵌入对话引擎
4. **文档驱动** — 架构变更必须先更新设计文档，再修改代码

## 模块职责

| 模块 | 职责 | 当前状态 |
|---|---|---|
| **Character Runtime** | 角色人格执行引擎，控制角色的一致性 | 🏗 待建 |
| **Memory Runtime** | 短期/长期记忆、关系记忆、生命事件 | 🏗 待建 |
| **Conversation Runtime** | 对话管理、上下文窗口、对话策略 | 🏗 待建 |
| **Persona System** | 人格定义、价值观体系、行为规则 | 🏗 待建 |
| **Provider Layer** | 外部服务适配器（LLM/TTS/Image） | 🏗 待建 |
| **Creator Studio** | 角色创建/编辑工具 | 📅 未来 |
| **Relationship System** | 用户-角色关系建模、亲密度、成长 | 🏗 待建 |

## 数据流向

```
用户输入 → Conversation Runtime
  → Persona System 注入人格指令
  → Memory Runtime 注入相关记忆
  → Character Runtime 筛选/约束输出
  → LLM Provider 生成响应
  → Memory Runtime 存储本次交互
  → 返回用户
```
