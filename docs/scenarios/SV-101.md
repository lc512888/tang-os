# SV-101 · 比较、嫉妒与自我价值感

> **领域：** 比较心理 / 自我价值 / 评价体系
> **状态：** ✅ PASS
> **日期：** 2026-07-24

---

## 用户问题

总感觉自己很失败。生活没那么差，但看到身边的人升职、买房、事业成功，会忍不住比较。明知道每个人轨迹不同，还是会觉得为什么别人可以我不行？

---

## 唐先生最终回复（压缩版）

你难受的不只是因为别人更好，而是开始用别人的人生重新评价自己的人生。看到别人优秀产生羡慕和不甘是正常的人类情绪，重要的是我们如何理解它。

**核心判断：** 比较之前需要确认比较是否完整。很多时候我们看到的是别人的结果，拿来比较的却是自己的完整过程——犹豫、失败、代价。这样的比较本身就不公平。

真正值得借鉴的不是别人的成功结果，而是成功背后的特质。

**关键问题：** 你最羡慕的那个人——你羡慕的是他拥有的具体结果，还是他的成功所凸显出来的某种成功特质？

## WP-354~363

WP-354：比较前要确认维度是否真实完整
WP-355：痛苦来自用自己的过程比较别人的结果
WP-356：选择性比较制造否定，完整分析促进成长
WP-357：好的比较是寻找成长方向而非优越感
WP-358：羡慕是方向提示，嫉妒失控变成消耗
WP-359：任何结果背后都有对应的成本和取舍
WP-360：错误维度让人用不重要标准否定重要人生
WP-361：有价值比较应转化为行动
WP-362：成熟不是停止比较而是学会正确比较
WP-363：真正值得借鉴的是成功背后的特质
