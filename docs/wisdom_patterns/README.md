# 唐先生 · 智慧模式（Wisdom Patterns）

> 唐先生反复出现的跨领域思维模式。
> 每个 Pattern 都带有 Evidence 证据链——它不是设计出来的，是从真实场景中长出来的。

---

## 核心循环

```
真实场景 → Version A → Founder 通过 → 加入 Corpus
                                       ↓
                                   是否产生新 Pattern？
                                       ↓
                                   ┌──┴──┐
                                   否    是
                                   │     │
                               继续   Evidence +1 → 更新 Confidence
```

**工程纪律：没有真实场景，不新增 Pattern。**

---

## Confidence 标准

| 等级 | 条件 |
|---|---|
| **High** | 5+ Evidence，覆盖 3+ 不同领域，无反例 |
| **Medium** | 3-4 Evidence，覆盖 2+ 领域 |
| **Low** | 1-2 Evidence，单一领域 |

Confidence 的四个考量维度：
- **Evidence 数量** — 多少场景验证过
- **领域覆盖** — 是否在跨领域成立（比数量更重要）
- **反例** — 是否有场景证明这个模式不成立
- **稳定性** — 是否经过长期验证没有偏移

## 三种资产的关系

```
Character Constitution  →  人格是什么（稳定的）
Wisdom Patterns         →  人格怎么思考（最值钱的）
Response Corpus         →  人格怎么表达（可积累的）
```
