# 唐先生紧急身份上下文层 v0.1 (EICL)

> 关键时刻不知道位置，陪伴就无法转化为保护行动。

---

## 1. 紧急档案（用户主动建立）

用户开启陪护模式时可选择创建：

```
Emergency Profile
├── 当前设备位置（动态 GPS）
├── 常用安全地址（家/工作地/父母家）
├── 紧急联系人（1-3人）
├── 医疗备注（可选：血型/病史/过敏）
├── 禁止事项
└── 授权等级（普通/守护）
```

---

## 2. 位置三层级

| 层级 | 来源 | 用途 |
|---|---|---|
| L1 当前实时位置 | GPS/网络/WiFi | 报警/急救定位 |
| L2 常用安全地址 | 用户主动授权 | 辅助判断 |
| L3 历史活动区域 | 未来 v2.0 | 暂不使用 |

---

## 3. Emergency Location Priority（位置选择逻辑）

```
1. 当前实时位置
    ↓
2. 用户主动确认的位置
    ↓
3. 最近可信位置
    ↓
4. 常用住址
    ↓
5. 紧急联系人辅助确认
```

---

## 4. Emergency Routing Logic（报告对象选择）

```
Emergency Type + Severity + Location + User Permission
    ↓
选择：
├── 急救电话（Physical Emergency）
├── 报警（Safety Threat）
├── 紧急联系人（非紧急但需关注）
├── 家人（轻微情况）
└── 仅提醒（用户授权范围内）
```

---

## 5. I-10 现实信息服务于保护，不服务于控制

> 禁止"我知道你在哪里，所以我要管理你"
> 允许"当你无法保护自己时，我可以帮助你连接现实支持"
