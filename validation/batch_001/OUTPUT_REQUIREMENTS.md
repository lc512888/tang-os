# Output Requirements v1.0 — Batch-001

## 禁止输出

- ❌ "很好"、"很先进"、"很像人"等主观评价
- ❌ 无 Spec ID 引用的个人意见
- ❌ "建议" 不附带理由

## 必须输出

### Section A: Understanding Result

Validator 如何理解 Tang OS？

### Section B: Compatibility Result

Spec → Implementation 的对应检查。

### Section C: Boundary Finding

检查是否出现：
- **Core Override:** Extension 修改 Identity
- **Authority Expansion:** Host 自己增加权限
- **Capability Escape:** Emergency Capability 绕过 Permission

### Section D: Specification Gap

发现规范不足时，必须引用 Spec ID，而非个人意见。
